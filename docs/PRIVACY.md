## 可用于审核的规则正文草案

### 一、服务与处理目的

“认真认识”首轮私人内测面向上海约 15–30 名成年人，为期待长期、排他性恋爱关系的人提供问卷初筛和人工审核的认识机会。第一阶段免费，不提供用户间聊天或公开档案。最新入口开放填写，无邀请码。介绍均由管理员亲自审核并明确授权，另分别征求两位参与者明确同意，确认要介绍的信息范围后才能人工进行。

个人信息处理者为【人工核验名称】，联系渠道为【人工核验联系方式】。规则版本为【已核验版本及生效日期】。尚未填写这些信息时仅允许模拟测试。

### 二、信息范围、来源与必要性

用户主动提供年龄、性别及愿意认识的约会对象性别、接受年龄范围、关系期待、参与匹配意愿、价值观、规划、亲密关系期待、沟通方式、兴趣与生活习惯及选填文字。联系方式选填、另表保管，单独确认同意用于管理员联系征求介绍意愿。技术信息包含匿名会话、同意版本、提交时间、限流摘要和安全审计。

不要求微信授权、传统账号、姓名、身份证、精确位置或地址。年龄只收周岁，不收生日。请勿填写他人信息或不必要的高度敏感文字。真实参与数据不得用于开发测试、模型训练或未经同意的其他目的。

### 三、敏感信息单独说明与同意

性别、约会对象偏好、关系期待、生育意向和文本可能揭示性取向及亲密关系。项目按高度敏感信息设计。核对双向对象偏好和关系期待是初筛的基础；必要性、是否存在更少信息的可行方案需人工评估。未经单独同意不能提交该问卷。泄露可能带来隐私、人格尊严、歧视或其他损害。

界面展示独立敏感说明与未默认选中的单独复选框。你可不同意并退出，不因此受到其他不相关服务的差别待遇。已同意后可撤回，系统即停止匹配并删除在线敏感回答及联系方式。

### 四、使用、访问和介绍

获授权的管理员只能在审核、人工匹配、征求双方意愿或处理用户权利请求时访问，敏感访问记审计。问卷不会向其他参与者公开，公开用户 ID 不能认证或访问回答。当前不启用算法评分、自动推荐或 AI；任何匹配均须管理员本人明确授权。不同性别、偏好及生活选择没有优劣。

CloudBase 作为大陆云托管和数据库服务提供方，具体地区、受托协议、子处理方、授权范围及保留周期须上线前核验。默认没有 AI 调用、境外服务或前端数据分析追踪。若未来引入 AI 或改变数据范围/目的，需重新评估并履行新的告知及所需同意，不能仅切换接口配置。

### 五、安全、保存及删除

使用 HTTPS、安全会话、独立随机恢复凭证、密码加动态验证码的管理员认证、数据库最小权限 RLS、回答及联系方式 AES-GCM 加密。敏感原始回答和联系方式不进入应用日志。加密仍不能替代操作权限、运营培训和安全验收。

当前保存配置为建立草稿或最后一次提交后 90 天，到期清理；上线前需设置合适期限并实际安排每日任务。撤回即停止参与并删除在线回答、联系和匹配结果；全部删除再清除身份及会话。受控备份在核验后的周期失效，恢复前重放最新删除台账，避免删除的数据复现。最小匿名 HMAC 审计摘要默认保留 180 天，具体依据待核验。

### 六、你的选择与权利

通过当前会话或安全恢复凭证查看、修改、撤回及删除自己的信息。修改重置审核及原介绍确认。联系方式可删除或更正，不强制提供。公开用户 ID 只用于沟通辨识。请保管凭证，勿分享给其他用户或管理员。

凭证丢失或对处理有疑问，请联系【已核验隐私渠道】；管理员按【核验方案】核实并在【响应期限】内处理请求。管理员不能只凭一个公开 ID 把答案发给提出请求的人。

### 七、变化与终止

处理目的、数据范围、敏感处理、第三方或保存方式发生实质变化时，负责人重新核验规则、版本告知及所需同意。关闭内测前通知参与者并执行撤回、删除、备份生命周期和审计保留计划。
