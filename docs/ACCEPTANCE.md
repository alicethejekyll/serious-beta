## 云端九项业务验收：均待腾讯云部署后执行

1. 两位不同受邀成年人用各自手机打开统一问卷入口；无邀请码，但必须完成成年及同意流程。
2. 模拟数据阶段验证完整提交；正式真实数据仅在安全及合规签核后处理。
3. 在 CloudBase PostgreSQL 查看实际新记录，重启服务后仍保存。
4. 管理员密码+TOTP 登录，查看刚提交回答，审计中出现敏感访问事件。
5. 复制并修改问卷草稿发布 v2，旧回答仍绑定 v1，新参与者绑定 v2。
6. 自动推荐和算法打分保持关闭。管理员手动建立候选，后端仍拦截基本条件不符合、拒绝或暂停的组合授权。
7. 记录候选与双方明确同意；即使双方同意也不可自行介绍。只有管理员近期 MFA 后明确批准才可标记可介绍，记录授权人、时间和审计；意愿改变撤销授权。
8. 用户撤回，回答/联系方式/匹配在线删除；用户再删除后恢复凭证失效。
9. 使用用户 A 的 cookie / 凭证请求用户 B 数据或管理员 API 全部拒绝；直接 PostgREST 无 rr schema 权限。

## 安全与运维验收

- [ ] 运行账号非超管/无 BYPASSRLS/无 INHERIT/非表所有者；所有表启用 FORCE RLS。
- [ ] 浏览器打包物无数据库连接、API Secret、应用密钥或管理员初始化凭证。
- [ ] 数据库 TLS 验证及内网连接，容器不能公网 HTTP 直连。
- [ ] 正确可信代理层数，伪造转发头不能绕过限流。
- [ ] 401、403、409、429、5xx 行为及断网不产生误报成功。
- [ ] 管理员停用立即失效；审计不可由业务管理员修改/删除。
- [ ] 网关与云日志不采集原始敏感回答、联系方式、Cookie 或恢复凭证。
- [ ] 正式规则主体、联系渠道、必要性/影响评估/受托协议人工核验。
- [ ] HTTPS、备案和实际域名验证通过；页脚真实备案号。
- [ ] 每日保留期清理任务成功并有失败告警；过期记录正确删除。
- [ ] 云备份和加密逻辑备份在境内私有保存，有核验的生命周期。
- [ ] 隔离恢复重放最新删除台账；恢复会话清空、问卷暂停，并进行双身份隔离复测。
- [ ] 外部安全审核签核，真实用户操作不进入测试数据/源码/提交记录。

全部验收后才把 DATA_MODE=real、LAUNCH_APPROVED=true 并配置已核验主体、联系渠道及规则版本。布尔开关只是技术防误启用，不能代替负责人完成真实验收。
