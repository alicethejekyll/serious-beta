# 安全设计与流程

## 身份与边界

- 开放入口可生成匿名用户；成年自我确认不是证件验证，不收集身份证。管理员应核验邀请群体均为成年，发现未成年立即撤回并删除。
- 恢复凭证为 CSPRNG 256 bit 随机值，数据库只存带服务端密钥的 HMAC。公开 `RR-` ID 在提交时随机生成，没有登录权力。
- HttpOnly / SameSite=Strict Cookie；生产 Secure，无 localStorage 回答、密码、恢复凭证。凭证仅在首次建立身份或轮换时返回给自己的已认证会话。
- 恢复撤销旧会话，轮换撤销其他会话；用户会话绝对 24 小时，管理员绝对 8 小时。会话 cookie 路径 `/api`。
- 管理员 scrypt N=32768 r=8 p=1 + 随机盐，TOTP 30 秒、±1 窗口、防重放。敏感读取、匹配及导出需最近 10 分钟 MFA；管理员账号停用每次请求立即生效。
- 所有 API 写入校验 Origin 和 JSON，认证写入再校验 CSRF。API 同源、不开放 CORS。DB 存储限流，支持多实例；默认用户提交每 IP 10 次/10 分钟、开放建草稿每 IP 50 次/小时、管理员登录 IP 5 次/10 分钟 + 账号 10 次/15 分钟。

## 数据与数据库

`users` 保存随机标识、恢复摘要、状态、有效期；`user_contacts` 另表保存联系方式；`responses` 和 `response_answers` 保存版本绑定及逐题加密值。另有要求中的问卷、版本、问题、邀请预留、匹配、反馈、管理员、审计，以及会话、同意、限流和配置表。

敏感回答/联系方式/管理员 TOTP/匹配报告/CSRF值使用 AES-256-GCM 加密。AAD 绑定用户、回答和题标识，不能交换密文到另一记录。元数据（状态、年龄以外的公开 ID、时间等）并非全部加密，仍按受保护信息限制访问。审计不保存回答或联系方式，不记录 request body、URL 查询、原始 IP、cookie 或恢复凭证。HTTP 网关须另外配置日志脱敏及禁止请求体/认证头采集。

`rr_runtime` 无继承、无超管、无 BYPASSRLS、非表所有者。事务按后端身份切换 rr_user/rr_admin/rr_auth/rr_maintenance；用户只能读写当前 rr.user_id 对应记录。数据库账户仅服务器保存。CloudBase anon/authenticated/service_role 没有 rr schema 授权；原生 PostgREST API 不暴露 rr。管理员路由全部由后端验证。

`rr_auth` 只负责认证和会话，能读恢复摘要和管理员密码摘要，不能读问卷答案；rr_admin 能读问卷和联系方式，但 API 分开访问并审计。rr_maintenance 可删到期记录，不能读敏感答案；删除级联由数据库执行。RLS 是应用身份之外的纵深保护，数据库凭证本身仍属安全边界，不可给浏览器。

## 版本与并发

- 草稿保存采用递增 revision；冲突返回 409，不静默覆盖另一页面修改。
- 同一用户只能有一个 response；提交事务完成版本校验和全题验证。重复提交返回相同随机 ID，不增加记录。
- 发布题目及版本由数据库 trigger 禁止原地修改；新参与者绑定当前版本，已有回答不自动搬移。
- 发布/暂停和开始/提交使用数据库 advisory lock 解决状态竞争。
- 修改已提交回答会重置审核状态并删除历史匹配及意愿，防止旧确认应用于新答案。撤回即删除在线回答、联系方式和匹配记录。

## 人工匹配与独立管理员授权

算法和 AI 暂缓设计。运行中的应用不自动推荐、不生成相容性分数、不启用权重编辑；旧分数不在工作台展示。保留的原型引擎仅供后续设计和隔离测试，未连接到应用流程。

仍校验不同用户、有效参与、成年及双向年龄区间、双向对象偏好、首轮关系期待、双方接受匹配、拒绝记录。这些只限制人工授权，不排序或打分。

建立候选记录默认为 pending。管理员本人需核对双方回答与基本条件、分别记录明确意愿并完成双方审核，然后使用近期 MFA、有效 CSRF 和明确确认字段调用独立授权接口。后端记录授权管理员、时间和审计。`canIntroduce` 必须同时满足有效人工授权、双方已审核、双方明确同意及当前基本条件通过，不能仅凭保存候选或修改前端获得授权。

任一方意愿改变会清除授权；拒绝立即禁止介绍。修改已提交回答、撤回或删除清除匹配；恢复备份将所有候选重置为待授权并清空旧分数。旧备份缺少新增授权列时按数据库默认值恢复，不能自动获得批准。系统只记录人工介绍状态，不发送联系方式或共享档案。

## 撤回、删除、备份

用户会话/恢复凭证可修改、撤回或硬删除自己的在线数据。删除级联清理回答、联系、匹配及会话；匿名 HMAC 审计目标保留用于恢复删除重放。过期清理同样生成台账。用户不提供真实数据用于开发测试。

管理员敏感详情、联系方式、匹配、导出及删除写审计；审计只可追加及读取，普通管理员不能修改或删除审计。维护任务按 180 天期限清理。备份及恢复流程见 DEPLOYMENT.md；上线前实际启用云备份、独立删除台账保存及 7 天备份生命周期，完成恢复演练。逻辑恢复自动撤销会话、暂停问卷，不自动开放真实数据。

## 上线仍需核验的外部安全项

CloudBase 数据库角色能力与 TLS CA、可信反向代理及客户端 IP、防火墙/网络隔离、HTTPS 网关与服务直连封锁、云日志脱敏、网关限流/告警、定时任务失败告警、备份存储生命周期、密钥管理与应急轮换、第三方渗透与越权复测。Docker 镜像构建、真机微信、云端压力及外部安全验收尚未执行。对 15–30 人 beta 做人工作业限制，并持续审查开放入口流量。

模拟与真实模式隔离用户会话、恢复及匹配参与；模拟记录不能在真实模式中获得人工匹配授权。生产使用独立空环境，禁止复用测试数据库。隔离恢复工具拒绝覆盖有用户、管理员或会话的数据库。
