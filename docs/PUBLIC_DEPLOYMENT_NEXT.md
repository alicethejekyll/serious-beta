以下仅说明 CLI 的源码上传方式，**不是当前可直接执行的完整发布命令**。只有云托管已开通、数据库最小权限与可信连接已通过核验、服务环境变量已安全注入，并完成实际 VPC 配置后才可执行；现阶段未执行上传或部署。

```sh
  --env-id serious-beta-d6gh7kuno620932cf \
  --service-name renzhen-beta-test \
  --source /absolute/path/to/renzhen \
  --port 8080
```
